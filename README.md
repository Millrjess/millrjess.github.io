# Jessica A. Miller — Portfolio Site

Website Operations Consultant. This repository is the source for https://millrjess.github.io/

Static site, no build step. Pages are plain HTML, CSS, and JavaScript, hosted on GitHub Pages.

## What is here

- `index.html` — Home, consulting offer
- `services/` — Services
- `fee-schedule/` — Rates and payment terms
- `booking/` — Book a free 15 minute discovery call, or a paid $200 strategy session
- `contact/`, `faqs/`, `about/`, `portfolio/`, `certifications/`, `testimonials/`, `resume/`, `books/`
- `wellness/` — A New Chapter wellness page
- `tracker/` — New Chapter: GLP-1 Tracker sales page
- `tracker-app/` — New Chapter: GLP-1 Tracker web app, with its own README
- `tracker-demo/` — Tracker demo
- `assets/` — Shared styles, scripts, images, and help chat
