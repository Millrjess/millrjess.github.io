Independent Usability Studies

Independent, not self-reviewed, usability studies coordinated from the beginning, through iteration, to implementation and launch, so a website is tested by real users before it goes live. I test a site as an outsider, not as its designer, so findings are not grading my own work.

  • Beginning: goals, user groups, tasks, and success measures agreed, with participants recruited to match those users
  • Iteration: small, moderated rounds, typically 5 users per user group per round, with fixes between rounds and a retest after changes
  • Implementation: prioritized findings and specific recommendations for design and development, including a website agent where a study shows customers need help online
  • Pre-launch checks: W3C validation, WCAG 2.2 AA accessibility, security and malware, speed, broken links and forms, and analytics
  • Taking a website to launch: findings, corrections, and retest results documented, with remaining issues and decisions requiring your input clearly listed

The proposal identifies the user groups, tasks, rounds, pages, and testing methods covered. See pricing for Independent Usability Studies.
